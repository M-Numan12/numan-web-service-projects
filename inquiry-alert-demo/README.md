# Inquiry Alert Queue

**Area:** Lead Generation

A browser-local notification prototype with no outbound alerts.

## Run locally

Open `index.html` in a modern browser. No build or dependencies are required.

## Workflow

1. Input: Incoming enquiry.
2. Process: Priority grouping.
3. Result: Alert queue.

## Scope

This prototype demonstrates a user journey in the browser. It is not a complete production implementation.

All example entries remain in memory. No external network requests are made by this demo. Before real deployment, add proper data storage, security controls, integration credentials, content and testing as needed.
